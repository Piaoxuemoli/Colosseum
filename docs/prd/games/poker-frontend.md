## 1. 场景定位与体验目标

德扑观战的气质与狼人杀相反：狼人杀是叙事（发言、投票、身份悬念），德扑是**数字博弈仪表盘**——筹码在流动、概率在隐现、多手牌以稳定节奏连续推进。观众的核心快感不是"听故事"，而是"读仪表"：一眼看清筹码压力、下注语言与运势曲线，再随时下钻到某个座位的思考链去看"为什么"。因此本页第一设计约束是：**数字永远先于叙事，思考链随时可下钻**。

| # | 目标陈述 | 验收口径 |
| --- | --- | --- |
| PG-1 | 3 秒读盘：任意时刻瞥一眼赛场，3 秒内能答出三问——谁的筹码最多？现在轮到谁行动？底池（含各边池）多少？ | 筹码最高座位、当前行动者标识、每个池的金额三者均有常驻视觉锚点（无需点击或滚动）；以对局中随机时刻截图做问答测试验证 |
| PG-2 | 每一手的三段式完整可循：发牌 → 四条街下注 → 结算；中途进场的观众也能拼出当前处于哪一段 | 街进度（翻牌前/翻牌/转牌/河牌）与手数常驻顶部状态条或赛场；一手内每个动作在行动流可回溯（FR-4.5-01 连续局口径） |
| PG-3 | 复杂结算不丢人：边池、平分、奇数筹码、多人全下 run-out，呈现后不需要懂 TDA 规则也能看懂"谁从哪个池赢了多少" | 结算逐池列出金额与归属；run-out 逐街揭示不跳步；与引擎结算数据人工对照无遗漏、无凭空数字 |
| PG-4 | 仪表与思考双焦点：数字节奏不被思考流打断，思考流也不被数字更新挤走 | 思考链完整驻留右侧思考 Tab（design-system"思考链一等公民"原则）；赛场动效不与思考气泡争抢注意力，紫色思考光效仅出现在思考语义上 |
| PG-5 | 中途入场 10 秒补课：从对局任意时刻进入，10 秒内完成局势重建 | 补课摘要（4.1）+ 首屏 ≤ 3 秒（NFR-01）联合验收 |

## 2. 赛场区（中央）布局需求

赛场区遵守 design-system 3.2 中央赛场契约：弹性主区、最小 640×480、内部禁止页面级滚动、按可用空间自适应缩放。桌面氛围使用场景色 `--color-scene-poker`（绿呢桌面与筹码高光），只用于赛场氛围渲染，不进入通用语义色体系。

### 2.1 牌桌与座位

**座位状态全集**（验收硬清单，对应 design-system 座位卡契约并按德扑细化；实现缺少任一状态即视为未完成）：

| 状态 | 呈现需求 |
| --- | --- |
| 存活 | 头像、Agent 名、筹码数（等宽、数值级字号）常态可见 |
| 当前行动者 | 全场最高优先级视觉锚点：座位描边或光圈 + "轮到 TA"文字并行标识（颜色不是唯一信息载体） |
| 正在思考 | 思考专属色光圈（维持"看到紫 = AI 在想"的条件反射），可与当前行动者态叠加 |
| 已弃牌（本手） | 座位压暗、手牌区收起；与淘汰态在视觉上不得混淆 |
| All-in | 强调呈现：全下徽章 + 筹码清零入池视觉（2.4）；run-out 与摊牌期间保持"在池"标识不消失 |
| 淘汰 | 置灰 + 名次徽章（按出局顺序标第 N 名）；座位保留占位（见 4.3） |
| 赢家高亮 | 结算时获胜座位成功色高亮；遵守胜负揭晓时刻感规范（≤1.2s、Esc 可跳过、其余区域轻微压暗） |
| 离线 / 调用异常 | 错误徽章组件：失败 / 重试中 / 持续失败升级提示（FR-4.4-04），不打断观战主流程 |

**位置标识**：庄家钮 D、小盲 SB、大盲 BB 以徽章钉在对应座位，每手开始随按钮移动更新；2 人 heads-up 时按钮与小盲同座，徽章并列呈现且不得误导。

**人数自适应（2-9 人）**：座位绕桌缘均匀分布；淘汰只改座位状态、不减座位数量，座位位置跨手保持稳定不跳动；9 人桌与 2 人桌都不得出现座位重叠、文字截断或牌桌比例失调；空间不足时优先压缩次要装饰，筹码数与位置徽章永不牺牲。

### 2.2 公共牌与底池

**公共牌**：
- 五个牌位常驻占位（暗牌背）；flop 三张同批揭示，turn、river 各一张；揭示顺序与引擎发牌事件一致，动效规格见第 5 节。
- 每张牌的点数与花色必须有文字或形状可读（颜色不是唯一信息载体）。

**底池与边池**（直接回应调研 §4 差距，P0）：
- 主池常驻桌心，金额等宽数字，变化用 300-400ms 数字滚动（design-system 数字滚动规范）。
- 出现 all-in 切池时，主池与每个边池**分别可视化**：逐池展示金额 + 该池归属范围（哪些座位有资格争夺此池）；all-in 玩家不得被呈现为可赢其无资格的外层边池。
- 多个 all-in 嵌套时按层级排列（主池居内，边池依次向外堆叠），每个池独立标注投入来源与资格范围。
- 平分（split pot）与奇数筹码归属在结算中逐池明示：谁分得多少、奇数筹码归了谁。

### 2.3 玩家手牌呈现（观众视角策略）

- **终局前**：默认隐藏各座位两张底牌（牌背占位），呈现与桌面玩家一致的公开视角。
- **摊牌时**：按引擎 reveal 事件顺序逐座揭示（river 有下注时最后进攻者先亮），不一次性拍出。
- **上帝视角开关**：是否允许观众终局前看穿底牌，列为开放决策 PK-1；若实现，须与 FR-4.4-01 的"上帝视角 / 仅公开视角"开关合一，且上帝视角信息有专属视觉区分（牌面描边或角标），默认关闭，切换不丢失观战进度。
- **弃牌座位的底牌**：默认视角收起；上帝视角（若启用）与回放中可回看。
- **摊牌解读（P0）**：摊牌完成后，赢家的 best-5（最优五张）在 7 张牌中高亮、未参与的 2 张降暗；同时以文字标注牌型名（如"两对：K 与 9，踢脚 Q"）；平分时逐赢家标注；牌型名不得只靠图形暗示。

### 2.4 筹码与下注呈现

- **每座位当前街下注额**：座位朝桌心一侧常驻展示本街已投入额（等宽小号数字 + 筹码视觉），随动作即时更新；各座位下注额对齐同一基准线，可直接目测比较。
- **街结束收池动画**：每条街结束时，各座位下注额汇入底池（筹码位移 + 底池数字滚动），"钱去了哪里"始终可读；收池后各座位下注额清零。
- **All-in 强调**：全下时筹码清零过程 + 全下徽章 + 一次性强调闪光（不循环，遵守"可长时间注视"原则）。
- **盲注与前注**：每手开始的 SB/BB（及 ante，若规则启用）以下注额形式出现在对应座位并带"盲注"类角标，不与普通下注混淆。

### 2.5 run-out 时刻（全员 all-in 的仪式感）

调研 §4 #12 指出现状在 river 前全员 all-in 时流程断裂；引擎修复后，这一时刻成为德扑观战最具张性的节点，呈现需求单列：

- **触发**：下注结束且无人可行动时，赛场进入 run-out 状态：全场轻微压暗，剩余发牌位点亮预告。
- **逐街揭示**：剩余公共牌按街逐批揭示（flop 一批三张、turn、river 各一张），街间有可感知的停顿节奏（页面级时长档），不允许一次性全部拍出。
- **在池座位底牌**：run-out 进入摊牌语义，所有在池座位底牌按摊牌规则揭示（全下摊牌无 muck 空间）。
- **逐池结算**：揭示完毕后按 2.2 / 2.3 的口径逐池宣布赢家与金额。
- **胜率快照**：run-out 期间是否展示各座位实时胜率，列为开放决策 PK-2。

## 3. 右侧面板 Tabs 需求

遵守 design-system 3.2 右侧面板契约（宽 360-480px、默认 400px、可拖拽调宽并记忆；六 Tab 固定为 状态 / 排名 / 行动 / 思考 / 印象 / 走势——德扑取"排名"形态；思考 Tab 有 Agent 思考中时显示计数角标；快捷键 1-6 切换）。

| Tab | 德扑内容需求 | 优先级 |
| --- | --- | --- |
| 状态 | 手数（第 N 手）、当前街（翻牌前/翻牌/转牌/河牌，配街进度指示）、当前盲注级别（SB/BB 数值，若规则启用 ante 一并显示）、下一盲注升级倒计时（按手数或时间计，与规则配置一致）、活跃玩家数 / 总人数、规则摘要（起始筹码、下注制） | P0 |
| 排名 | 实时筹码榜：按当前筹码降序、等宽数字、行内头像与名次变化指示（升/降）；淘汰者沉底并标名次；榜首与赛场筹码最高座位视觉呼应（服务 PG-1） | P0 |
| 行动 | 人类可读动作流（FR-4.4-03）：每条含主体、动作类型、数值、所在手与街的锚点；**加注条目必须带 min-raise 语境**——"加注到 240（最小加注到 160）"，使观众能分辨最小加注 / 超额加注 / 不足额全下；兜底动作带兜底标记（FR-4.4-04）；手与街的分隔清晰，新到达高亮、支持回放定位 | P0 |
| 思考 | 按手分组的思考链：手数 → 座位 → 动作前思考（人类可读摘要 + 可展开原始全文，FR-4.4-02）；流式更新；与赛场"正在思考"座位联动 | P0 |
| 印象 | Agent 间印象记录（更新痕迹、置信度可视化、矛盾提示）——平台通用能力，德扑不做特化 | P1 |
| 走势 | 筹码曲线：横轴为手数（多手轴）；每座位一条分色曲线（配色与座位视觉锚点一致）；**盲注升级以竖线标记、淘汰事件以曲线终点标记**（标名次）；悬停查值（该手结束后各家筹码）；支持子集对比；回放模式下与回放进度联动 | 曲线本身 P0（FR-4.5-01）；对比与联动细节 P1 |

## 4. 关键交互流程需求

### 4.1 中途进入对局（补课摘要）

- 首屏 ≤ 3 秒呈现当前态势（NFR-01），加载期呈现场态骨架而非白屏。
- 就绪后呈现一段**补课摘要**（约 10 秒可读完）：当前手数与街、筹码前三、本手已发生动作数（可一键展开本手行动流）、盲注级别与距下次升级。摘要为浮层或面板顶部条，可手动关闭，不阻塞实时更新。
- 中途进入不重播历史动画，直接落在当前态势。

### 4.2 一手结束的结算呈现

- 结算即胜负揭晓时刻：遵守 design-system 揭晓规范（获胜座位光圈扩散、展示级字号、其余区域轻微压暗、总时长 ≤1.2s、Esc 可跳过）。
- 揭晓后保留一段非模态结算摘要：**谁赢了多少（逐池）**、以什么牌型赢（对照摊牌）、平分时逐赢家份额与奇数筹码去向。
- 未摊牌的取胜（全员弃牌）同样明确呈现：赢家高亮 + 拿池金额，无牌型标注。
- 手与手之间有清晰状态分隔（"第 N 手结束 → 第 N+1 手"）；新手的盲注投入与按钮移动可见。

### 4.3 淘汰时刻

- 座位筹码归零出局：进入淘汰态（置灰 + 名次徽章）+ 一次性强调动效（不循环）；行动流与状态 Tab 同步"某 Agent 淘汰（第 N 名）"。
- 淘汰座位保留占位与名次，兑现 2.1 的座位稳定承诺；其走势曲线以终点标记收束。
- 终局（只剩一人）：进入对局结算（FR-4.6-01），赛场定格为终局态势快照，排名与过程数据可回推验证。

### 4.4 多级盲注升级的预告

- 状态 Tab 常驻"距下一级盲注升级还剩 X 手（或 X 分钟）"倒计时；临近阈值（默认最后 1 手 / 1 分钟）时在顶部状态条或赛场边缘出现非阻塞预告（warning 语气），不弹模态框。
- 升级发生时：状态 Tab 数值更新 + 行动流插入级别条目（"盲注升级：SB/BB 25/50 → 50/100"）+ 走势图立即出现升级标记线。

### 4.5 回放模式特有（承接 FR-4.6-02 / FR-4.6-03）

- 回放控制条吸附于顶部状态条：播放/暂停、倍速 0.5-8x、逐事件步进、进度拖拽、跳到手数。
- **跳手**（按手牌跳转）与**跳街**（手内按翻牌前/翻牌/转牌/河牌跳转）双粒度；阶段列表完整无遗漏。
- 单步步进时每个事件（发牌、reveal、收池、盲注）都有可定格的中间态；回放不重算、不改写事件。
- 回放中座位卡呈"历史定格"状态；思考链回放支持单选手视角过滤（仅该座位的思考 + 动作）。

## 5. 动效与实时性需求

全部动效落在 design-system 时长阶梯（`--motion-instant` / `--motion-fast` / `--motion-normal` / `--motion-slow` 与页面级 350-500ms 档）与缓动 tokens 内；`prefers-reduced-motion` 时按规范降级；每段动效必须回答"什么变了"，无装饰性动效。

**三类德扑核心动效规格**：

| 动效 | 规格 |
| --- | --- |
| 翻牌（公共牌揭示） | 牌翻入或滑入牌位，单张进入用 `--motion-normal`；flop 三张以约 80-120ms 错开依次落位，总时长 ≤ 500ms；落位后点数花色立即可读 |
| 摊牌（底牌揭示） | 按 reveal 顺序逐座揭示，每座进入 `--motion-fast`、座间隔 150-250ms；best-5 高亮以一次透明度 / 描边过渡完成（`--motion-normal`），不闪烁 |
| 收池（筹码入池） | 分街结束收池与结算派彩两类：筹码位移 + 底池 / 座位数字滚动（`--motion-slow`，300-400ms，等宽保证不抖动）；增减方向的瞬时闪光一次，不循环 |

**实时性与批量更新**：
- 遵守 design-system 第 6 节：100-150ms 窗口内多条事件合并为一次渲染（与 rAF 对齐）；一条街内连续密集动作不逐条抖动，数字滚动可合并到终值。
- 动作发生到观众可见端到端 ≤ 2 秒（NFR-03，不含 LLM 思考时长）；连接状态徽章三态常驻顶部状态条。
- 行动流与思考流遵守跟随 / 锚定规则：默认跟随最新，上滚即锚定并显示"回到最新"浮标。
- 赛场同时活跃的动画数量有节制（思考光圈、行动者高亮、数字滚动并存时不超载），保证数小时观战不疲劳。

## 6. 边界与降级

- **断线重连（NFR-05）**：连接徽章三态（正常 / 降级重连中 / 失联）；重连成功先静默补齐增量，缺口过大时显示"已追至第 N 手"摘要条并触发一次补课摘要（4.1），不整页刷新、不重播错乱。
- **Agent 超时与兜底折叠**：超时或失败被兜底接管（fold/check）时，座位短暂出现错误徽章，对应动作条目带兜底标记，展开可见失败原因类别与重试情况（FR-4.4-04）；观战主流程零弹窗中断；持续失败升级为常驻错误徽章。
- **长局性能（NFR-02，100+ 手）**：行动流与思考流超过约 200 条必须虚拟化；走势图数据点超过可视像素 2 倍时降采样（保留极值点）；事件缓冲有上限、更早内容按需分页；交互响应 < 200ms；长时间观战内存不持续增长。
- **结算密集流**：一手结束后若下一手已开始，结算摘要自动收起为行动流中的手级条目（可点开回看），浮层不堆积。
- **极端牌局**：9 人嵌套多池、连续平分、奇数筹码等组合场景下，逐池呈现不得溢出、遮挡或截断（允许滚动或折叠，但金额与归属必须可读）。

## 8. 验收标准（清单式）

- [ ] 布局契约：顶部状态条（对局名、游戏类型、手数、当前街、阶段计时、连接徽章、回放控制条吸附位）+ 中央赛场（≥640×480、无页面级滚动）+ 右侧面板（默认 400px、六 Tab）逐项与 design-system 3.2 对齐。
- [ ] PG-1 读盘测试：随机时刻截图，3 秒内可答"筹码最多者 / 当前行动者 / 各池金额"。
- [ ] 座位状态全集（2.1 表）逐项触发验证：存活 / 思考 / 行动者 / 弃牌 / all-in / 淘汰（含名次）/ 赢家高亮 / 离线，且颜色均有文字或图标并行标识。
- [ ] 位置徽章 D / SB / BB 每手正确轮转；2 人 heads-up 时按钮与小盲同座呈现正确。
- [ ] 2、6、9 人对局座位环桌自适应：无重叠、无截断，筹码数与徽章始终可读；淘汰不减座位、位置跨手稳定。
- [ ] 公共牌：五牌位常驻，flop / turn / river 按街揭示，动效符合第 5 节规格，reduced-motion 下降级。
- [ ] 边池：构造 ≥2 层嵌套 all-in 场景，主池与各边池金额、投入来源、归属范围逐池可视；all-in 玩家不被呈现为可赢其无资格的外层池；平分与奇数筹码归属逐池明示。
- [ ] 摊牌：按 reveal 顺序逐座揭示；赢家 best-5 高亮 + 牌型名文字标注（平分时逐赢家）；全员弃牌取胜有明确呈现。
- [ ] run-out：全员 all-in 后逐街揭示（不一次拍出）、底牌揭示、逐池结算，全程与引擎事件一致、无中断跳步。
- [ ] 下注呈现：各座位当前街下注额常驻可比；街结束收池动画后清零；盲注投入有角标区分。
- [ ] 右侧面板：状态 Tab 含手数 / 街 / 盲注级别 / 升级倒计时 / 活跃玩家；排名为实时筹码榜；行动条目含 min-raise 语境与兜底标记；思考按手分组、可展开原始全文；走势曲线含盲注升级线与淘汰终点标记。
- [ ] 关键流程：中途进入 10 秒补课摘要；结算摘要逐池列出赢家 / 金额 / 牌型；淘汰有一次性强调 + 名次；盲注升级有预告、级别条目与走势标记；回放支持跳手 / 跳街 / 逐事件步进与单选手视角过滤。
- [ ] 实时性：100-150ms 批量合并不逐条抖动；端到端 ≤ 2s；行动 / 思考流跟随与锚定行为正确；断线重连三态 + "已追至第 N 手"。
- [ ] 边界：超时兜底零弹窗、原因可查；100+ 手长局虚拟化 / 降采样生效、交互 <200ms、内存不增长；极端多池组合下金额与归属仍可读。
- [ ] 品质：颜色 / 字号 / 间距 / 动效全部来自 tokens；数字等宽；场景色只用于赛场氛围、思考紫不被挪用；键盘可达（1-6 切 Tab、空格回放播放暂停、Esc 跳过揭晓）；正文对比度 ≥ 4.5:1。
