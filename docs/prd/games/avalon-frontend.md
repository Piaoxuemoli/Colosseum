## 1. 场景定位与体验目标

阿瓦隆是**无淘汰的全程博弈**：没有死亡信息差，全部张力来自「发言说服 → 记名表决 → 任务结果推理 → 刺杀悬念」。体验目标：

1. **任务板即记分牌**：5 轮任务进度与 3 胜赛点一目了然，观众随时知道「好人还差几个成功」「第 4 轮双失败意味着什么」。
2. **发言即主战场**：讨论阶段的发言流是核心内容，呈现优先级高于机械动作。
3. **记名投票可追溯**：谁赞成谁反对构成推理链条，可回查。
4. **刺杀是终局高潮**：好人 3 成功 ≠ 结束——刺杀合议与指认要有独立的仪式感呈现。
5. **上帝视角的信息差可视化**：观众可一眼看到「梅林知道什么、坏人知道什么、派西维尔在纠结什么」。

## 2. 赛场区（中央）布局需求

### 2.1 任务板（态势核心，P0）

呈现元素：
- 5 轮任务槽横排：每槽显示本轮任务人数、双失败轮标记（需要 2 张失败牌的轮次有显式图标）、当前轮高亮。
- 每槽结果态：成功（圆蓝）/ 失败（叉红）/ 进行中 / 未开始；失败槽显示失败张数。
- 赛点条：好人成功数 vs 坏人失败数（3:3 制）+ 连坐计数器（本轮第几次提案，5 次封顶警告：第 4 次拒绝后显示「再拒一次坏人直接获胜」警示）。
- 数据来源 = 公共任务结果与表决事件，任何视角可见（不含私有信息）。

### 2.2 玩家呈现：座位卡状态全集（P0）

每名玩家一张座位卡，显示：
- 座位号、名称、头像、当前队长徽标（轮值队长）、待行动高亮（正在思考 / 等待其行动）。
- 角色徽标：**上帝视角**显示角色与阵营色（好人蓝 / 坏人红）；**公开视角**终局前不显示任何身份；终局揭示后全员翻牌。
- 知识连线（上帝视角专属面板，见 2.5）：不画在座位卡上，避免视觉过载。
- 本局个人可追溯记录摘要：发言次数、表决立场史（迷你时间线：每轮一次赞成 / 反对色点，可 hover 查看对应提案）、被提名次数、任务参与及该轮任务结果。

### 2.3 阶段氛围（P1）

阶段驱动的视觉状态：讨论（暖色、发言气泡形态）→ 提名（队长大厅色）→ 表决（逐人投票进度）→ 任务（保密暗色调 + 出牌人数进度）→ 刺杀合议（红色暗调 + 「坏人密谋中」标记）→ 刺杀指认（聚光灯效果，被指认者高亮）→ 终局（全翻牌 + 胜方阵营色）。

### 2.4 发言 / 讨论呈现（P0）

- 讨论阶段发言流：座位序逐条呈现发言人 + 全文（引擎载荷透传，不截断存储；UI 可折叠长文）。
- 刺杀合议（上帝 / 坏人视角）：显式区分于公开讨论的视觉容器（密谋气泡），公开视角下该容器显示为「坏人正在密谋（不可见）」占位。
- 发言与思考链分离：发言是公开事件流内容，思考链仍在平台右栏（FR-4.4-02），不混排。

### 2.5 投票与任务呈现（P0）

- 记名表决：表决阶段逐人亮立场（座位卡即时角标 + 时间线条目「X 赞成 / X 反对」）；汇总条显示赞成 vs 反对计数与结果。
- 任务执行：显示队伍成员出牌进度（已出 N / 队伍 M），**不显示任何人立场**（终局前含上帝视角）；结算动画显示结果 + 失败张数（「1 张失败牌」是推理锚点）。

### 2.6 刺杀环节呈现（P0，全量化核心增量）

- 好人 3 成功瞬间：任务板先呈现赛点达成，再切「刺杀环节」横幅——**明确传达「好人还没赢」**。
- 密谋容器（见 2.4）→ 指认动画：刺杀者座位高亮 → 被指认者座位标记 → 结果揭晓（指认梅林 = 坏人翻盘红屏 / 指认错误 = 好人胜利蓝屏）。
- 终局揭示：全员翻牌 + 胜方 + 依据（「任务 3:1」或「刺杀命中梅林」）。

### 2.7 知识面板（上帝视角专属，P1）

终局前的上帝视角附加面板：按知识矩阵（AVR-203）可视化「谁看到谁」——梅林 →（除莫德雷德外）坏人；派西维尔 → 梅林 + 莫甘娜（并列不标注）；坏人互识（奥伯伦单向）。观众借此理解 Agent 推理的信息基础。

## 3. 右侧面板 Tabs 需求（P0）

平台统一右栏框架内新增阿瓦隆专属 tab：
- **发言流**（默认）：讨论发言 + 记名表决 + 提案 + 任务结果的统一中文动作流（FR-4.4-03 口径）。
- 平台既有 tabs（思考链 / 异常 / 用量等）直接继承，不重复定义。

## 4. 组局配置面需求（P0）

创建阿瓦隆对局的表单升级：
- 板子预设选择器：v1 提供 6 种内置预设（基础 5 / 欺瞒 5 / 影主 5 / 基础 6 / 孤王 6 + 7–10 人扩展板按需展开），选中预设显示阵营构成、任务人数表、双失败轮说明。
- 玩家选择数量随板子人数联动；主持人 Agent 可选（默认无，AVR-OD-6）。
- 赛前密钥健康检查与上传链路复用平台既有机制（FR-4.1-03），无阿瓦隆特例。

## 5. 关键交互流程需求（P0）

### 5.1 中途进入补课

观众中途进入时，由公共事件流重建任务板 / 表决史 / 发言史完整状态（AVR-501 重放口径的前端投影）。

### 5.2 视角切换

上帝（默认）/ 公开 / 单玩家三视角（AVR-205）：切换不丢进度；公开视角下知识面板与密谋内容遮蔽；单玩家视角复刻该玩家信息面。

### 5.3 回放模式

- 阶段跳转锚点 = 5 轮任务轮次 + 刺杀环节（与 FR-4.6-02 统一控制条）。
- 发言流回放与任务板状态严格同步（跳到某 seq 时任务板呈现该时刻战绩）。

## 6. 边界与降级

- 事件流含未知事件类型（前后端版本错位）：静默忽略，任务板按已知事件降级呈现，不白屏。
- 引擎配置无讨论阶段（AVR-101 参数 9 关）：跳过发言流呈现，直接提名。

## 7. 开放决策（2026-09-09 已由产品代理代决）

| 编号 | 决策 | 选项 | 代决结论 |
|---|---|---|---|
| AF-OD-1 | 座位布局形态 | 圆桌环 / 横排卡组 | **横排卡组**（5–10 人弹性布局，环形在 8 人以上可读性差；与平台设计系统网格一致） |
| AF-OD-2 | 知识面板分期 | v1 / v2 | **v1 交付简版**（按知识矩阵静态连线，不做动画推演） |
| AF-OD-3 | 通用兜底渲染去留 | 阿瓦隆专属后删除兜底 / 保留 | **保留**（NFR-08 兜底路径是平台资产，专属投影失败时回落） |

## 8. 验收标准（清单式）

- [ ] 任务板：5 轮槽 + 双失败标记 + 赛点条 + 连坐计数完整呈现，随事件实时更新。
- [ ] 座位卡：队长徽标 / 待行动高亮 / 视角相关的角色呈现 / 表决立场迷你时间线。
- [ ] 发言流：讨论发言全文 + 密谋容器的视角遮蔽。
- [ ] 记名表决逐人呈现 + 汇总；任务出牌进度（不露立场）+ 失败张数。
- [ ] 刺杀环节完整仪式：赛点横幅 → 密谋 → 指认 → 揭晓。
- [ ] 三视角切换 + 中途进入补课 + 回放阶段跳转（轮次锚点）。
- [ ] 组局面：6 预设选择器 + 人数联动 + 密钥检查复用。
- [ ] 未知事件降级不白屏。
- [ ] 呈现契约四支柱符合性检查通过（平台统一门禁）。
