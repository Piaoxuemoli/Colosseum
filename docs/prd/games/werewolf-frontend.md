> 定位声明：本文件是**狼人杀观战界面**的信息架构与体验需求权威，细化 design-system 3.2 观战页布局契约与 PRD FR-4.5-02 在狼人杀品类上的落地，不与两者冲突；冲突时以上游为准。本文属需求体系：只描述要达成什么、验收什么，不出现源码路径、组件库名与实现选型。本文词汇一律沿用 design-system 的组件与 token 体系（座位卡、思考气泡、阶段指示器、场景色 tokens 等）。

## 1. 场景定位与体验目标

德扑观战页的气质是「数字仪表盘」：筹码、底池、赔率与走势曲线，关键信息是数值。狼人杀观战页的气质是「社交推理剧的直播间」：语言是主要内容本体，局势藏在发言、投票与死亡里；观众追的不是数字而是戏——谁在表演、谁在撒谎、谁被推了出去。但剧情感不等于装饰：底色、信息密度、动效克制仍完全遵守 design-system 第 1 节原则，戏剧性只来自两处——关键时刻的仪式感（2.5 节）与上帝视角信息的可信呈现（2.1 节）。

观众在任意时刻必须能零成本回答四个问题：**谁在说、谁可疑、谁死了（怎么死的）、现在是什么阶段**。以下目标可独立验收：

| # | 目标陈述 | 验收口径 |
| --- | --- | --- |
| G1 | 阶段感知零成本：不滚动、不点击，1 秒内读出「第几天/夜、当前阶段、谁在行动」 | 状态条（天数 + 阶段 + 计时）与赛场氛围（昼夜视觉）双通道同时呈现；在对局任意时点抽查均可答对 |
| G2 | 上帝视角全知且不混淆：观众默认可见全部身份、死因、夜间动作，且始终能分辨「哪些是选手看不到的」 | 承接 FR-4.4-01；每条上帝视角信息带稳定可学的并行标识（图标或文字，不以颜色为唯一载体） |
| G3 | 关键时刻有仪式感：死讯、平安夜、双死、开枪、翻牌、警徽移交、终局揭晓均以「时刻」呈现，观众不错过也不被打扰 | 2.5 节公告清单逐项可演示；每个时刻动效总时长落在预算内且可跳过 |
| G4 | 中途入场 30 秒补课：从进入进行中对局到能复述当前局面（天数、死亡名单、警长、正在发生什么）不超过 30 秒 | 4.1 节局面摘要卡呈现且不遮挡赛场；首屏 ≤3 秒（NFR-01） |
| G5 | 数小时可注视：12 人局长局（引擎防死锁天数上限内）连续观战不产生视觉疲劳 | 无循环闪烁类动效；同屏活跃动画有节制；`prefers-reduced-motion` 全量降级可用 |

## 2. 赛场区（中央）布局需求

赛场区遵守 design-system 3.2：弹性主区、最小可用 640×480、内部禁止页面级滚动、按可用空间自适应缩放。场景氛围使用场景色 tokens（`--color-scene-werewolf`：夜空蓝底 + 月光点缀），场景色只渲染赛场氛围，不进入通用组件语义（design-system 2.1）。赛场区内部结构：

```
┌─────────────────────────────────────────────┐
│  座位环桌（沿外圈布置 N 个座位卡，死亡者原位置保留） │
│   ┌───────────────────────────────┐         │
│   │  中央主持台：阶段氛围 + 主持人公告 +  │         │
│   │  当前发言者气泡（发言 / 遗言 / 密语）  │         │
│   └───────────────────────────────┘         │
├─────────────────────────────────────────────┤
│  发言流：历史发言 / 遗言气泡，按天与夜分组滚动     │
└─────────────────────────────────────────────┘
```

### 2.1 玩家呈现：座位卡状态全集

座位卡在 design-system 4.2 通用七状态（存活 / 淘汰 / 正在思考 / 当前行动者 / 赢家高亮 / 离线断连 / 回放历史定格）之上按狼人杀扩充，下表为验收硬清单，缺任一状态即视为未完成：

| 状态 | 触发时机 | 呈现要点 |
| --- | --- | --- |
| 存活（默认） | —— | 头像 + 座位号 + Agent 名 |
| 死亡（出局） | 夜死宣布 / 放逐 / 枪杀 / 殉情 / 自爆 | 原位置保留、整体置灰；出局轮次可见；死因可见性见下方口径 |
| 正在思考 | 夜间行动决策 / 白天准备发言 | 思考态光圈（思考专属色）；同时多人思考时仅当前行动者保留动效 |
| 当前发言者 | 白天发言 / PK 发言 / 竞选演讲 | 高亮 + 中央主持台气泡联动 |
| 遗言中 | 有遗言权的出局者 | 与普通发言可区分的特殊标识（「遗言」标签） |
| 正在投票 | 放逐 / 警长竞选投票进行中 | 投票中状态可见 |
| 被投票（计票中） | 同步投票亮票过程 | 被投票数徽章实时累加（2.4 节） |
| 佩戴警长徽章 | 当选警长；移交后转移 | 徽章常驻佩戴者座位；移交 / 撕毁作为公告时刻（2.5 节） |
| 上警候选 / 已退水 | 首日警长竞选 | 竞选中候选标识；退水者保留退水标记（其无警长投票权） |
| 白痴翻牌（存活无票权） | 被放逐翻牌免死 | 双重标识：仍存活 + 无投票权；不被误读为死亡 |
| 离线 / 兜底接管中 | LLM 调用失败或超时 | 错误徽章关联呈现（第 6 节），不弹窗 |
| 赢家高亮 | 终局 | 阵营胜利方高亮（4.2 节） |
| 回放历史定格 | 回放模式任意时点 | 与 design-system 座位卡回放态一致 |

**死亡呈现与「观众上帝视角」原则**（本节为狼人杀观战的第一原则）：

1. 死因口径：选手之间死因隐藏是游戏规则（暗牌局靠遗言有无与翻牌与否推断刀 / 毒 / 枪）；**观众默认上帝视角，死因（狼刀 / 毒 / 枪杀 / 放逐 / 殉情 / 自爆）与出局轮次全量可见**。观众所见 = 主持人所知的全部。
2. 观战呈现与选手决策输入完全隔离：观众全知绝不改变对局内任何选手的信息结构——上帝视角是呈现层能力，不是对局信息面的一部分（调研 §3.3 信息可见性矩阵的产品化表述）。
3. 全部上帝视角信息（身份、死因、夜间动作、狼队密语、验人结果、刀口与用药）必须有与公开信息稳定可辨的视觉区分（统一「全知」角标或边线语义），且不以颜色为唯一信息载体。
4. 死亡座位保留原位置不移除，保证天数推进时的空间记忆连续；连锁死亡（枪杀、殉情）按结算时序先后呈现。
5. **沉浸模式**（W-1 已代决：一键全遮）：承接 FR-4.4-01「仅公开视角」开关——身份、死因、夜间动作整体遮蔽为公开口径；切换即时生效且不丢观战进度；不做分级遮蔽，单选手视角（4.3 节回放）后置合并。

### 2.2 日 / 夜氛围：阶段驱动的视觉切换

| 阶段 | 氛围需求 |
| --- | --- |
| 夜晚 | 夜空蓝成为赛场主导，月光点缀做低频微光；上帝视角在状态条与主持台显示「当前行动角色」（如「女巫行动中」），沉浸模式仅显示「夜晚进行中」 |
| 白天 | 夜色退为底，赛场整体提亮一档（仍在暗色体系内），座位环与发言流成为视觉主角 |
| 警长竞选（首日） | 焦点光聚于上警者；警上 / 警下、退水状态在座位层可辨 |
| 放逐投票 | 计票视觉主导：票数徽章与票向为最高层级信息 |
| 终局 | 压暗 + 阵营揭示（4.2 节） |

切换约束：阶段间氛围过渡 250-400ms（`--motion-normal` 至 `--motion-slow`）；「天黑 / 天亮」作为时刻允许至 500ms；过渡不得阻塞交互；`prefers-reduced-motion` 时改为纯透明度切换；同屏同时只允许一个氛围过渡。阶段指示器（当前 / 已完成 / 即将到来 / 计时进度，design-system 4.2）按实际序列展开：夜间各角色阶段 → 白天公告 → 遗言 → 发言 → 投票 → 结算；「第 N 天 / 第 N 夜」计数常驻顶部状态条。

### 2.3 发言呈现

- **当前发言者**：座位卡高亮 + 中央主持台显示其发言气泡（流式更新）；发言者切换以 `--motion-normal` 过渡；「下一个发言者」可预期——发言顺序的可视化口径（从死者下一位开始 / 警长决定 / 按座位）与引擎宣告一致，让观众跟上轮到谁。
- **历史发言气泡**：赛场区发言流按天与夜分组滚动；遵守跟随 / 锚定规则（design-system 第 6 节）：默认跟随最新，用户上滚即锚定并出现「回到最新」浮标。
- **思考气泡与发言气泡严格区分**：思考链一律用思考专属紫 + 边线 + 标签；发言气泡用常规形态（场景点缀色只做氛围）。「看到紫 = AI 在想」的条件反射在狼人杀页同样成立，发言气泡不得使用紫色系。
- **密语（上帝视角信息）**：狼队夜间合议、女巫用药独白、预言家验人自语等选手间不可见的内容，气泡带「密语」可见性标识；沉浸模式下遮蔽。
- **遗言**：特殊气泡形态并标注「遗言」；无遗言权的死亡在公告中以「无遗言」标注——遗言有无是公开信息，是观众与选手共享的推理线索（如被毒无遗言）。
- 发言气泡默认全文流式呈现、超长自动折叠（W-3 已代决）。

### 2.4 投票呈现

- **进行中**：显示已投 / 未投进度（N/M）；实时计票可视——每个座位卡的被投票数徽章实时累加，上帝视角同时可见票向流向；全部亮票后一次性呈现完整票型。
- **加权与资格**：警长票权加成（按板子配置 1.5 或 2 票）在票数与提示中显式标注；弃票、退水者与白痴翻牌者的无票权状态可见——票权资格的呈现与引擎裁决一字不差。
- **平票 PK 轮**：进入 PK 的双方获得醒目标识，呈现 PK 发言与再投票；再次平票时公告「本轮无人出局」（平安日）。
- **警长竞选投票**：警下投票资格矩阵（警上者与退水者无票权）、当选公告；再平票或吞警徽时公告「本局无警长」。
- **警徽流**：警长（通常为跳预言家者）事先宣告的警徽流向作为可追踪信息呈现在状态 Tab（3.1 节）；移交 / 撕徽作为公告时刻（2.5 节）。
- 历史票型可在投票历史图谱（3.6 节）与回放中复查。

### 2.5 死讯 / 平安夜 / 双死与公告的仪式感

- 公告 = 主持人的**流程性宣告**，属规则必需，不可关闭（FR-4.7-01：仅解说性旁白可关）；台词在主持台呈现并进入动作流。
- 必须作为「时刻」呈现的公告清单：天黑 / 天亮、死讯（死亡人数 + 座位号）、**平安夜（显式文字公告，不得省略——无人死亡本身是关键公共信息）**、双死（两死者座位；上帝视角附各自死因，公开口径不显示死因）、自爆（白天发生、直接入夜、竞选阶段则吞警徽）、猎人开枪、白痴翻牌、警徽移交 / 撕毁、放逐出局、终局揭晓。
- 仪式感约束：以主持台为主场——其余区域轻微压暗、展示级以内字号强调，单个公告时刻总时长不超过 1s（终局揭晓 ≤1.2s，可 Esc 跳过）；公告文案与引擎事件一字不差，不虚构、不改写、不提前泄露未宣告内容；连锁事件（双死 + 翻牌 + 开枪）合并为一个时刻序列依序呈现，不逐条打断。

## 3. 右侧面板 Tabs 需求

遵守 design-system 3.2：面板宽 360-480px（默认 400，可拖拽并记忆），Tab 结构固定六枚，快捷键 1-6，思考 Tab 有思考活动时显示计数角标。第六槽位「走势」在狼人杀无筹码曲线对应物，以**投票历史图谱**替代（3.6 节；W-2 已代决：轮次 × 玩家矩阵），Tab 数量与顺序不变。各 Tab 内容定义：

| Tab | 内容定义 |
| --- | --- |
| 状态 | 阶段指示器全序列；天数计数；存活 / 死亡计数；**死亡名单**（座位、出局轮次、死因——上帝视角全列，沉浸模式仅「出局」口径）；阵营态势（上帝视角：存活狼 / 神职 / 平民数与胜利条件距离，沉浸模式隐藏）；警长在位与警徽流宣告；板子与规则摘要（构成、胜负口径、关键规则参数） |
| 名册 | 阵容信息矩阵：每行一个座位——座位号、Agent 头像与名、身份（上帝视角可见；翻牌或终局后按实际口径标注）、存活状态、票权（正常 / 加权 / 无）、遗言状态；上帝视角列带统一标识；终局全揭示后切换为完整身份表 |
| 行动 | 人类可读中文动作流（FR-4.4-03）：谁 + 做了什么 + 结果；阶段锚点（第 N 夜 / 第 N 天 / 竞选）；类型图标（发言 / 投票 / 夜间动作 / 公告 / 异常）；夜间动作条目带上帝视角标识（沉浸模式遮蔽）；发言条目可定位跳转到完整气泡；兜底标记可展开失败原因；新到达高亮；超长虚拟化 |
| 思考 | **按天与夜分组**的思考链：每条含人类可读摘要 + 可展开原始全文 + 时间戳（FR-4.4-02）；正在思考者的气泡流式更新；夜间决策思考（狼队合议、神职行动）与白天发言思考以分组与标签区分 |
| 印象 | 按「怀疑谁 / 信任谁」组织的印象卡：新建、更新痕迹、置信度可视化、矛盾提示（design-system 4.2 印象卡契约）；是观众「谁可疑」之问的持久面板；上帝视角下可与真实阵营对照，看出谁的判断错了 |
| 走势（替代） | 投票历史图谱（W-2 已代决形态）：轮次 × 玩家矩阵——每行一轮投票（警长竞选、各日放逐、PK 再投），单元格为票向与得票，行尾标注结果（出局 / 平安日 / 无警长）；悬停查票型明细；回放联动定位；玩家色锚点与名册一致 |

## 4. 关键交互流程需求

### 4.1 中途进入对局的补课

- 进入进行中对局：≤3 秒呈现当前完整态势（NFR-01），加载期为态势骨架而非白屏。
- 呈现「当前局面摘要」卡：天数与阶段、死亡名单（含上帝视角死因）、警长与警徽流、当前行动者、最近一条公告；用户一次操作可收起或自动折叠，收起前不遮挡赛场主体。
- 从摘要到细节 ≤2 次点击：点击死者可见其遗言与死因，点击阶段可见阶段指示器上下文。
- 跳转途中对局结束：不报错，落在结算页并提示「对局刚刚结束」（与 lobby-home 3.1 口径一致）。

### 4.2 终局揭晓与角色全揭示

- 触发口径随板子呈现：屠边（杀光神职边或平民边）、屠城、狼人全灭、强制结束或防死锁平局（须标注「人为终止」或「强制平局」及终止时点，承接 FR-4.3-03）。
- 揭示时刻：胜负揭晓动效（获胜方座位光圈扩散、展示级字号、其余区域压暗，总时长 ≤1.2s，Esc 可跳过）；随后全桌翻牌——每个座位卡揭示身份与阵营标识，狼队同伴关系可视化（谁与谁同队）。
- 揭示后：名册切换为完整身份表；结算数据（天数、获胜阵营、关键局面的过程可验证性）承接 FR-4.6-01；提供回放入口。
- 上帝视角观众「早已知道结局」——揭示时刻对两类观众一致呈现（仪式感不因视角缺席）；沉浸模式观众在此刻一次性补齐全部信息。

### 4.3 回放模式特有需求

- 回放控制条吸附于顶部状态条（design-system 3.2）：播放 / 暂停（空格）、倍速、逐事件步进、进度拖拽。
- 阶段跳转：阶段列表**按昼夜轮次完整无遗漏**（FR-4.6-02）——第 N 夜（可细至角色行动阶段）、第 N 天（公告 / 遗言 / 发言 / 投票）、警长竞选各环节；跳转后正确重建该时刻完整态势（含当时死亡名单与其死因口径）。
- 按玩家过滤：单选手视角 = 仅该选手的思考与动作轨迹（FR-4.6-03）；与沉浸模式组合即得「他所知道的世界」（联动 W-1）。
- 回放中座位卡呈历史定格态；任何事件回放口径与实时观战留痕一致，不重算、不改写。

## 5. 动效与实时性需求

- 总口径：动作发生到观众可见端到端 ≤2 秒（NFR-03）；100-150ms 窗口内多条事件合并为一次渲染，新内容不改变当前滚动位置（design-system 第 6 节）。
- **发言类**：气泡进入为淡入 + 上移 4px（`--motion-fast`）；流式追加新文本低透明度渐实、不整体跳动；发言者高亮切换 `--motion-normal`。
- **死亡类**：座位卡状态迁移 250-400ms 一次完成，出局后不循环闪烁；遗言气泡进入同发言类；死讯公告时刻 ≤1s（2.5 节）。
- **计票类**：票数徽章数字滚动 300-400ms（等宽字体不抖动）；亮票与出局 / 当选结果做一次方向性强调，不循环。
- **氛围类**：昼夜与阶段切换遵守 2.2 节时长与节流约束；同屏活跃的思考光圈与氛围过渡总数有节制，超出时仅当前行动者保留动效。
- `prefers-reduced-motion`：全部位移动画改为纯透明度切换或静止；数字滚动直接显示终值并闪烁一次；胜负揭晓保留静态高亮。

## 6. 边界与降级

- **观众断线重连**：连接徽章三态（正常 / 降级重连中 / 失联）；重连成功先静默补齐增量，缺口过大显示「已追至第 N 天 / 夜」摘要条，不整页刷新（NFR-05 + design-system 第 6 节）。
- **agent 长时间无响应**：等待态可见而不焦虑——状态条阶段计时持续走，当前行动座位呈现「谁在行动 + 已等待时长」的轻量提示；不弹窗、不用全屏转圈；超时后由兜底接管（FR-4.4-04），观众侧仅在动作流见到标记。
- **兜底动作的观战呈现**：透明但不打扰——主界面无错误弹窗、观战不中断；对应动作条目带兜底标记，展开可见失败原因类别（超时 / 鉴权 / 额度 / 非法输出）与重试情况；座位卡关联错误徽章；对局页有「本局异常 N 次」汇总入口。
- **规则性长间歇**：连续多夜或长时间等待时赛场保持稳定氛围与等待态，不制造假动态填充（G5）。
- **移动端（<768px）**：单栏堆叠，顶部状态条 + 赛场优先，六 Tab 折叠为赛场下方可切换区；允许整页滚动（design-system 3.1 豁免）；触控目标 ≥44px；赛场形态按 W-4 已代决口径：<768px 座位网格化列表，<480px 再降至发言流为主视觉、座位折叠为状态条。
- **极端数据**：行动与思考流超约 200 条虚拟化；长局观战内存不持续增长（design-system 第 6 节）。

## 8. 验收标准（清单式）

- [ ] 布局契约：顶部状态条（48px：局名、品类、第 N 天/夜、当前阶段、阶段计时、连接徽章、回放条吸附）+ 中央赛场 + 右侧六 Tab 面板（360-480px，默认 400 可拖拽记忆）；100dvh 内无整页滚动。
- [ ] 座位卡状态全集（2.1 节 13 态）逐项可演示，含死亡原位保留置灰、警长徽章、遗言中、被投票数、白痴翻牌双标识、兜底接管。
- [ ] 观众上帝视角：身份、死因（刀/毒/枪/放逐/殉情/自爆）、夜间动作、狼队密语、验人结果实时全见，且每条带非颜色的并行标识；开启沉浸模式后全部收敛为公开口径且不丢进度。
- [ ] 公告清单（2.5 节）逐项呈现：平安夜显式文字公告、双死显示人数与座位、自爆直接入夜、天黑/天亮时刻；文案与引擎宣告一致；流程性宣告不可关闭。
- [ ] 日夜氛围随阶段切换（夜 / 昼 / 警长竞选 / 投票 / 终局），过渡 250-400ms（天黑天亮 ≤500ms），reduced-motion 降级为透明度切换。
- [ ] 发言呈现：当前发言者高亮 + 主持台气泡流式；发言流按天/夜分组、跟随/锚定/回到最新；思考紫仅用于思考气泡；密语有可见性标识；遗言形态可区分。
- [ ] 投票呈现：进行中实时计票与票向、警长加权与无票权资格显式、平票 PK 轮与再平票「无人出局」、警长竞选全程（上警/退水/警下投票/无警长/吞警徽）。
- [ ] 警徽流宣告可在状态 Tab 追踪；移交/撕毁作为公告时刻呈现。
- [ ] 右侧六 Tab 内容符合第 3 节定义：状态含死亡名单与死因口径、名册矩阵、行动流中文可读且夜间动作带标识、思考按天/夜分组带计数角标、印象卡、第六 Tab 为投票历史图谱（或 W-2 拍板形态）。
- [ ] 中途进入：≤3 秒完整态势 + 局面摘要卡（天数/死亡名单/警长/当前行动/最近公告），摘要到细节 ≤2 次点击。
- [ ] 终局：揭示时刻 ≤1.2s 可 Esc 跳过；全桌翻牌 + 阵营与狼队关系可视化；强制结束/平局有标注；结算承接 FR-4.6-01。
- [ ] 回放：控制条吸附状态条；阶段列表按昼夜轮次完整无遗漏可跳转；单选手视角过滤；回放与实时留痕一致。
- [ ] 动效合规：三类动效（发言/死亡/计票）落在 design-system 时长阶梯内；批量合并 100-150ms；无循环闪烁；reduced-motion 全量降级。
- [ ] 边界：断线重连三态徽章 + 静默补齐 + 「已追至第 N 天/夜」摘要；agent 无响应有等待态不弹窗；兜底动作带标记可展开原因，主界面无错误弹窗。
- [ ] 无障碍：正文对比度 ≥4.5:1；关键结果 aria-live 广播；键盘可达（1-6 切 Tab、空格回放、Esc 跳过揭晓）；颜色不是唯一信息载体。
- [ ] 性能：首屏 ≤3s（NFR-01）、端到端 ≤2s（NFR-03）、数百事件交互 <200ms（NFR-02）；长局内存不增长。
- [ ] 移动端（<768px）：单栏、赛场优先、Tab 折叠、触控目标 ≥44px、允许整页滚动。
