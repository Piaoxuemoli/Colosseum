> 定位声明：本文件是 Colosseum 前端的**唯一视觉与交互需求权威**。v2.0 起全线转向**高级中国水墨风格**：玄墨暗色基底 × 宣纸留白 × 墨分五色 × 朱砂点睛，每个游戏在总纲下有独立的墨韵变奏。v0.1 的控制台风格全部退役，现有实现不构成任何约束。本文是需求体系：tokens 为需求级建议值（允许微调色相），层级语义与对比关系不可破坏；不绑定实现文件结构。

## 1. 设计原则（v2）

1. **玄墨为底，宣纸为面** —— 全站基底是近黑的暖墨色（如夜色中的宣纸），内容表面以「墨阶」分层；杜绝 v0.1 冷蓝灰的机房感。
2. **墨分五色** —— 全部灰阶由「焦、浓、重、淡、清」五阶墨派生（偏暖、偏茶色相），任何界面元素不得引入冷蓝灰族。
3. **朱砂点睛，惜红如金** —— 朱砂红是唯一的高强度强调色，只用于主 CTA、危险语义、刺杀仪式与终局胜者章。「满屏皆红 = 没有红」。
4. **留白即层级** —— 大厅、列表、配置页采用文人画式疏朗留白（区块间距慷慨、卡片内呼吸充分）；观战页保留高信息密度（观战是分析工具），以墨线分隔与纸色分层替代边框墙。
5. **一游戏一墨韵** —— 德扑·青花、狼人·夜月、阿瓦隆·朱砂：同一玄墨宣纸底上，各自以晕染色、纹样母题与印章标识变奏；进入对局即入画境。
6. **思考链 = 花青** —— AI 推理过程的全站统一视觉标识从紫色改为花青（靛蓝族），「看到花青晕 = AI 在想」；花青不得用于其他语义。
7. **书法气质，数据冷静** —— 标题、品牌、发言引文用楷书体（霞鹜文楷族）传达文人气质；数值、时间戳、筹码、ELO 一律等宽字体保持竞技严肃性。
8. **动效如墨入水** —— 动效只做四件事：墨晕展开（新内容进入）、印章落定（状态终结）、墨滴呼吸（进行中）、笔锋掠过（hover）。全部缓动用减速曲线。
9. **可长时间注视** —— 数小时观战不疲劳：暖色低饱和底、无大面积高频闪烁、动效频率有节制（沿袭 v0.1）。
10. **中文优先排版** —— 沿袭 v0.1：中文基线、标点悬挂、中英数字混排间距。

## 2. 视觉语言

### 2.1 色彩体系

| Token | 建议值 | 墨阶 | 用途 |

| `--ink-canvas` | `#14110D` | （夜宣） | 页面最底层画布 |
| `--ink-1` | `#1D1914` | 焦→浓 | 第一层表面：面板、卡片、导航底 |
| `--ink-2` | `#26211A` | 重 | 第二层表面：悬浮、下拉、弹层 |
| `--ink-3` | `#332C22` | 淡 | 第三层表面：输入底、hover、日志底 |

**游戏墨韵变奏（场景 token，只用于赛场氛围与游戏专属元素）**

| 游戏 | 变奏名 | Token | 建议值 | 气质与母题 |
| --- | --- | --- | --- | --- |
| 德州扑克 | 青花 | `--wash-poker` | 钴青 `#2E5E8C` / 青白 `#9FC3E8` | 青花瓷纹样的牌桌雅趣 |
| 狼人杀 | 夜月 | `--wash-werewolf` | 墨蓝 `#232B3D` / 月白 `#D6ECF0` | 夜色晕染与月光 |

变奏规则：同一时刻页面**最多一层主变奏**（进入对局观战后）；大厅与通用页变奏色只允许极小面积（品类标识印章）。

### 2.2 字体

| 层 | 字体栈 | 用途 |
| --- | --- | --- |
| 书法层 | `'LXGW WenKai Screen', 'Kaiti SC', 'STKaiti', serif`（霞鹜文楷屏幕版，开源可商用，CDN 引入，`font-display: swap`） | 品牌题字、页面主标题、发言引文、游戏名 |
| 界面层 | `'PingFang SC', 'Microsoft YaHei', system-ui, sans-serif` | 正文、控件、表单、导航 |
| 数据层 | `'JetBrains Mono', 'SF Mono', Consolas, monospace` | 筹码、ELO、seq、时间戳、牌面符号 |

规则：书法层不用于小于 14px 的文字与长正文；发言流正文可用书法层（「人说的话」带书写气质）。

**字号阶梯（6 级，沿袭 v0.1）**：展示 24px/1.3 · 标题 18px/1.4 · 正文 14px/1.6 · 辅助 13px/1.5 · 微缩 12px/1.5 · 数值 16-28px/1.2（等宽）。正文默认不小于 13px。

### 2.3 密度与栅格（沿袭 v0.1 骨架，密度分档放宽）

- 8px 基准网格；间距 token `--space-1..8`（4/8/12/16/24/32）。
- **两档密度**：观战页维持紧凑（控件 28-32px、行高 36-40px、面板内边距 12-16px）；大厅/列表/配置页放宽（控件 32-36px、行高 44px、卡片内边距 16-24px）。
- 圆角：`--radius-sm`(4px) 基础件 · `--radius-md`(8px) 卡片 · `--radius-lg`(12px) 浮层。水墨卡片的圆角取下限（越接近直角越像册页）。
- 浮起语义：第 1 层 = 1px 墨线；第 2 层 = 墨线 + 柔影 `0 4px 16px rgba(0,0,0,.35)`；第 3 层（对话框/Toast）= 双钩线 + `0 8px 32px rgba(0,0,0,.5)`。

### 2.4 图标

线性 stroke 图标（1.5px，沿袭 v0.1）；水墨语境下允许两类定制：月相图标（狼人昼夜）、印章图形（品类/胜者）。不使用拟物填充图标。

### 2.5 质感母题

| 母题 | 规格 | 用途 |
| --- | --- | --- |
| 墨线 | 1px `--ink-line`；重要面板「双钩」内外双线 | 容器边界 |
| 墨晕 | `radial-gradient` 变奏色 → 透明，透明度 ≤12% | 赛场背景、hover 晕、状态晕 |
| 宣纸纹 | CSS 多层极低对比渐变噪点（无图片依赖），仅 `--paper-wash` 层 | 终局揭示、公告纸面 |
| 印章 | 朱砂/变奏底 + 反白篆字意象（书法层 + `border` 拟章），轻旋 -3°~3° | 品类标识（德/狼/瓦）、胜者章、「我的」章 |
| 笔触分隔 | 高度 2px、中段渐透明的墨线 | 区块标题装饰分隔 |
| 竖排题字 | `writing-mode: vertical-rl`，装饰性短句 ≤8 字 | 大厅侧栏题字、观战品类题款 |

## 3. 布局系统

### 3.1 全局骨架

左侧窄导航（64px，悬停展开 224px）+ 主内容区（沿袭 v0.1 结构）。导航换血：底色 `--ink-1`；激活态为朱砂小方章（代替色条）；品牌区竖排题字「竞技场」+ 英文小字；观战页侧栏自动收窄行为保留。

### 3.2 观战页布局契约（核心页面）

左（赛场）/ 右（面板）/ 底（回放控制条）三栏结构沿袭——密度优先。新增：赛场顶部游戏题款（书法体游戏名 + 变奏印章）；阶段切换时全屏 300ms 变奏色墨晕扫过（入夜加深 / 任务亮起）。

### 3.3 大厅 / 列表 / 配置页布局契约

- 大厅：v0.1 五区**信息架构**保留，视觉重排为立轴式——书法体大标题、区块间距放大一档、卡片为册页式（墨线 + 微纸纹）、品类用印章标识。
- 列表行：行高 44px，分隔用笔触分隔弱化版。
- 配置页：分步表单保持，右侧预览卡改画框式（双钩边框 + 变奏晕）。

## 5. 动效规范

| 动效 | 曲线/时长 | 场景 |
| --- | --- | --- |
| 墨晕展开 | ease-out 240ms | 列表项/卡片进入、面板展开 |
| 印章落定 | cubic-bezier(0.34,1.56,0.64,1) 360ms | 终局、确认操作、胜者章 |
| 墨滴呼吸 | ease-in-out 2.4s 循环，半径 ±6% | 直播指示、思考光效 |
| 笔锋掠过 | ease-out 120ms | hover 边框亮起、链接下划线 |
| 变奏晕扫 | ease-in-out 300ms | 观战页阶段切换 |

全部动效支持 `prefers-reduced-motion` 降级为透明度切换；观战页常驻动效不超过三处。

## 6. 实时性与数据展示规则

沿袭 v0.1 第 6 节全部规则（批量合并 100-150ms / 时间线跟随态滚动）。「墨闪」：数值变化时 240ms 花青或朱砂高亮渐隐。

## 7. 游戏墨韵变奏细则

### 7.1 德州扑克 · 青花

赛场底：钴青晕 + 青白纹样边（毡面深青）。筹码 = 青花瓷片（圆片描青花边）；公共牌 = 瓷白卡面 + 青花角饰；花色符号青色族；阶段条（翻牌/转牌/河牌）青花渐变；结算青花「胜」章。注：青花**印章底色**允许在全值基础上降饱和（如 `#416088`），避免小面积高饱和蓝与朱砂争辉——晕染底色仍用全值 `--wash-poker`。

### 7.2 狼人杀 · 夜月

赛场底：墨蓝夜空晕；昼夜切换 = 全屏墨色加深/褪去 + 月相图标循环。座位卡纸面 + 墨线；死亡 = 卡面覆淡墨（毛笔划痕意象）+ 灰度；夜间面板边缘泛月白微光；发言气泡书法体引号；结算胜方阵营章（狼=夜月章、好=竹青章）。

### 7.3 阿瓦隆 · 朱砂

赛场底：玄墨 + 战旗式朱砂晕（左上斜向）。任务板册页式 5 槽：成功 = 竹青「成」印、失败 = 朱砂「败」印（StampReveal）；双失败轮槽边鎏金。座位卡：队长鎏金「令」章；表决立场朱砂/竹青小点。刺杀仪式：全屏朱砂晕 + 聚光被指认者 + 终局大印章（命中=「弑」、未中=「护」）。发言流：讨论书法体；密谋深色晕底 + 朱砂引号。

## 8. 无障碍与品质基线

沿袭 v0.1 第 7 节：正文对比度 ≥4.5:1（月白 #EAE3D2 于 #14110D ≈13:1 ✓；朱砂底反白 ≈5.5:1 ✓）；键盘可达 + 焦点环（墨线双环）；颜色不是唯一信息载体（印章带文字）；`prefers-reduced-motion` 全量降级。

## 9. 组件技术选型（DS-OD-1..3，2026-09-11 代决）

| # | 议题 | 决策 | 理由 |
| --- | --- | --- | --- |
| DS-OD-1 | 组件库路线 | 保留 shadcn 式自建组件体系（CSS variables + Tailwind 4），以 token 全量重定义实现水墨化；不引入 Shuimo UI（Vue 系栈不兼容，仅作视觉参考） | ① 现有组件全站消费，token 级替换成本最低零功能回退；② CSS variables 机制天然支持整套主题切换 |
| DS-OD-2 | 字体引入 | 霞鹜文楷屏幕版经 CDN（jsDelivr npm 包）引入，`font-display: swap`；数据层保持等宽栈 | 开源可商用、楷体气质契合、屏幕版可读性优化 |
| DS-OD-3 | 亮/暗基底 | 玄墨暗色单一基底（不做亮色宣纸模式，留作远期开放决策） | 与「长时间注视」原则一致 |
